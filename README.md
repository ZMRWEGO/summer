# 悬于天际

使用 Vite 和 Three.js 构建的交互式三维布料网站，支持风力调节、拖拽和背景配乐。

- 网站：<https://summer.spring-smart.com>
- 代码仓库：<https://github.com/ZMRWEGO/summer>
- 部署：GitHub `main` → Vercel → Cloudflare DNS

## 本地开发

使用 Node.js 22.12 或更新的 22.x 版本。

```sh
npm ci
npm run dev
```

## 构建和预览

```sh
npm run build
npm run preview
```

构建输出为 `dist/`。部署设置和更新流程见 [DEPLOYMENT.md](DEPLOYMENT.md)。
